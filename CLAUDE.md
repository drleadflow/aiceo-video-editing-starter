# Video editing starter

Read README.md and docs/WORKFLOW.md before editing. Preserve originals and use new version directories. Keep all recordings, transcripts and derived assets under ignored projects/. Do not add personal media, credentials, client images or private vault links to this repository.

Inspect the source and transcript before choosing cuts. Never invent spoken words. Record kept source ranges and retime captions when cuts change. Do not treat a silence threshold as evidence of a mistake.

Use the two-line title preset and one clear visual per concept. Keep text off faces and inside mobile safe areas. B-roll should illustrate the actual words. No duplicate shots without a narrative reason.

HyperFrames owns timed media playback. Use unique IDs, an explicitly sized root and one paused timeline with the matching composition ID. Animate visual wrappers, not timed clips. Run the installed HyperFrames check and inspect encoded frames. Listen to dialogue joins before claiming audio review.

Use local assets and available transcripts first. Get authorization before new paid API calls or uploads. Only publish a video or enable a messaging automation when authorized. Never claim ordinary chat has local file execution access unless the current environment provides it.

## Starter routing
Use edit-video for a full edit, hook-variations for alternate openings, and optional
higgsfield-broll or heygen-presenter only when needed. Canonical skills live in
.claude/skills; npm run sync:skills mirrors them into .agents/skills for Codex.
No global skill installation is needed. Read docs/PROVIDERS.md before provider work.
Preserve user authorization; do not repeat approvals already supplied.
